# 🍐 Pear Store | Interface de E-commerce

Projeto de desenvolvimento web inspirado na experiência visual de lojas de tecnologia, com identidade inspirada em uma marca fictícia presente no seriado iCarly e foco em uma interface moderna, intuitiva e interativa.

## 💻 Sobre o projeto

O **Pear Store** é um projeto de front-end desenvolvido com HTML, CSS e JavaScript, simulando a apresentação de smartphones em uma loja virtual.

O objetivo é colocar em prática conhecimentos de estruturação de páginas web, estilização de interfaces e manipulação de elementos com JavaScript.

## 🚀 Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, cores, tipografia e layout.
- **JavaScript:** implementação de interatividade e comportamento dinâmico.

## ✨ Funcionalidades

- Interface inspirada em lojas de tecnologia.
- Menu de navegação com categorias de produtos.
- Apresentação do smartphone Pear Pro.
- Seleção entre quatro cores: azul, preto, rosa e vermelho.
- Exibição de imagens dos produtos.
- Botões e elementos visuais de navegação.

Durante o desenvolvimento, pratiquei a organização de arquivos HTML, CSS e JavaScript, a utilização de caminhos relativos para imagens e a publicação de projetos utilizando GitHub Pages.
